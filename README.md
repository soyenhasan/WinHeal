# WinHeal AI 🚀
An AI-powered automated Windows utility designed to diagnose system health, clear temporary junk files, and optimize overall PC performance locally without needing a cloud server.

## Features
- **System Diagnostics:** Monitors CPU, RAM, and Disk usage in real-time.
- **Junk File Cleaner:** Automatically clears temporary and cache files to free up space.
- **Self-Healing Automation:** Executes lightweight Python & PowerShell scripts to fix common performance lags.

## Tech Stack
- **Language:** Python
- **Platform:** Windows (Desktop Utility)
