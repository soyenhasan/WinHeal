### ✨ Features (v0.2.0 Pro)

- 🧹 **Smart Temp Cleaner** - Deep scans and cleans Windows TEMP files
- ⚡ **RAM Optimizer** - Shows real-time RAM usage and optimization tips
- 📊 **Live Stats** - Shows how many files and how much MB is junk
- 📈 **Progress Bar** - Real-time cleaning progress
- 🎨 **Pro Dark UI** - Beautiful, modern, and lightweight
- 🇧🇩 **Made in Bangladesh**
